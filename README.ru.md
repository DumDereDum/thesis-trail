# ThesisTrail

[ENG](README.md) | **RUS**

Инструкции и шаблоны для работы с ИИ, которые помогают студенту подготовить и защитить курсовую или диплом, а научному руководителю — проверить работу и подготовить вопросы.

## Установка

Запустите команду в папке своего проекта для установки из самого свежего по дате тега версии. Нужны Bash, Git и curl.

```bash
curl -fsSL https://raw.githubusercontent.com/DumDereDum/thesis-trail/main/scripts/install.sh | bash
```

[Подробности установки](docs/install.md).

Агенты с подключёнными инструкциями проверяют новые версии не чаще раза в сутки и спрашивают перед обновлением. [Подробнее об обновлениях](docs/update.md).

## После установки: работа над темой

Сценарий с карточкой темы ещё не выпущен и не входит в `v0.0.2`.

Откройте проект в ИИ-агенте, который читает `AGENTS.md`, и напишите, например: «Давай начнём работу над курсовой». Если ваш клиент не читает `AGENTS.md`, настройте чтение `.tt/agent-rules.md`. Установка сама по себе не запускает агента.

Агент использует ваше сообщение и предоставленные материалы, уточнит недостающие сведения и поможет создать `docs/topic.md`: тему на русском и английском, тип работы, курс и уровень образования, направление подготовки и краткое описание. Неизвестные поля можно оставить незаполненными; предложенный английский перевод считается предварительным, пока вы его не приняли. Карточка создаётся во время беседы, а не установщиком.

Дальше общайтесь обычными сообщениями: «Проверь введение» или «Руководитель согласовал новое название, обнови карточку». В следующих сессиях агент читает карточку и вносит принятые изменения. Карточка принадлежит вам и сохраняется при обновлениях ThesisTrail. [Описание сценария](docs/student-workflow.md).
