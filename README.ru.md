# ThesisTrail

[ENG](README.md) | **RUS**

Инструкции для ИИ-агента, которые помогают студенту подготовить и защитить курсовую или диплом, а руководителю — проверить работу и подготовить вопросы.

## Установка

Выполните в папке проекта. Нужны Bash, Git и curl. Команда выбирает самый свежий по дате тег версии.

```bash
curl -fsSL https://raw.githubusercontent.com/DumDereDum/thesis-trail/main/scripts/install.sh | bash
```

[Подробности установки](docs/install.md). Агент проверяет обновления не чаще раза в сутки и спрашивает перед их применением.

## После установки: работа над темой

1. Откройте проект в ИИ-агенте, который читает `AGENTS.md`.
2. Напишите одно из сообщений:

   - **В проекте уже были файлы:** «Подготовь проект из бэкапа».
   - **Проект был пустым:** «Давай начнём работу над курсовой».

3. Агент восстановит материалы, уточнит недостающие сведения и создаст или дополнит `docs/topic.md`.

**Карточка темы:** тема на русском и английском, тип работы, курс и уровень образования, направление подготовки и краткое описание. Неизвестные поля можно оставить незаполненными; предложенный перевод остаётся предварительным до вашего принятия.

**Бэкап:** существующие файлы временно окажутся в `.tt/backups/project-…/`. Агент должен вернуть их в рабочие папки и проверить восстановление. Бэкап не переносится через Git; удалять его можно только по вашей просьбе после проверки.

Дальше пишите: «Проверь введение» или «Обнови согласованное название темы». Подготовка не повторяется, ваши документы сохраняются при обновлениях.

Установка сама не запускает агента. Если клиент не читает `AGENTS.md`, подключите `.tt/agent-rules.md` вручную. [Работа с темой](instructions/research/topic.md) · [Подготовка из бэкапа](instructions/maintenance/project-setup.md).

## Исходные материалы

Агент организует оригиналы и создаёт каталог с карточками:

```text
materials/                         # Оригиналы, локально
├── articles/                      # Статьи
├── books/                         # Книги
├── regulations/                   # Нормативные документы
├── guidelines/                    # Методические материалы
└── other/                         # Остальные источники
docs/
├── materials.md                   # Общий каталог
└── materials/
    └── articles/example.pdf.md    # Карточка materials/articles/example.pdf
```

Оригиналы исключаются из Git, каталог и карточки сохраняются. После клонирования оригиналы нужно предоставить заново или получить по сохранённым ссылкам.

**Карточки материалов:** содержание, польза для работы, источник, версия и фактически изученные страницы. Непрочитанные документы отмечаются явно; для цитат и ответов агент проверяет оригинал.

Если `materials/` занят кодом или ресурсами проекта, агент сохраняет его назначение и выбирает свободную `research-materials/` для источников. В начале сессии он сообщает о новых или отсутствующих файлах библиотеки; исправляет расхождения по вашему поручению.

Можно поручить поиск:

> По моей теме найди пять релевантных статей, скачай их и заполни карточки с каталогом.

Нужны инструменты поиска и скачивания в клиенте агента. Он проверит источники и отдельно сообщит, что найдено и что удалось сохранить.

[Правила библиотеки и поиска](instructions/research/materials.md).

## Структура инструкций

[Точка входа](instructions/agent-rules.md) подключает подходящие для задачи разделы:

```text
instructions/
├── agent-rules.md             # Точка входа и выбор инструкций
├── general/                   # Общие правила проекта
│   ├── git.md                 # Ветки, коммиты и публикация
│   ├── reproducibility.md     # Запуск и повторение экспериментов
│   └── documentation.md       # README и документация
├── research/                  # Исследовательская часть
│   ├── topic.md               # Тема и крупные решения
│   └── materials.md           # Источники и карточки материалов
├── maintenance/               # Обслуживание ThesisTrail
│   ├── project-setup.md       # Подготовка проекта из бэкапа
│   └── updates.md             # Обновления
└── domains/                   # Предметные области
    └── README.md              # Каталог предметных инструкций
```

Предметные разделы, например `domains/ml/`, добавляются по мере появления инструкций.

В проекте студента инструкции находятся в `.tt/`; в `AGENTS.md` добавляется подключающий блок. `.tt/.gitignore` исключает бэкапы и локальное состояние, сами инструкции доступны для Git. Папка `docs/` этого репозитория содержит спецификации для разработки ThesisTrail и студенту не устанавливается.
