# ThesisTrail

[ENG](README.md) | **RUS**

Инструкции и шаблоны для работы с ИИ, которые помогают студенту подготовить и защитить курсовую или диплом, а научному руководителю — проверить работу и подготовить вопросы.

## Установка

Запустите команду в папке своего проекта для установки из самого свежего по дате тега версии. Нужны Bash, Git и curl.

```bash
curl -fsSL https://raw.githubusercontent.com/DumDereDum/thesis-trail/main/scripts/install.sh | bash
```

[Подробности установки](docs/install.md).

Агенты с подключёнными инструкциями проверяют новые версии не чаще раза в сутки и спрашивают перед обновлением. [Подробнее об обновлениях](docs/update.md).

## После установки: работа над темой

Сценарий с карточкой темы ещё не выпущен и не входит в `v0.0.2`.

В версиях с [первичной подготовкой проекта](docs/project-setup.md) первая установка переносит существующие материалы в отдельную папку `.backup/project-.../`. `.git`, `.tt` и предыдущие бэкапы остаются на месте; корневые инструкции сохраняются, а в `.gitignore` добавляется `/.backup/`. Исходные файлы находятся в архиве, пока агент не скопирует их обратно. Обновления не повторяют этот перенос.

Откройте проект в ИИ-агенте, который читает `AGENTS.md`, и напишите: «Подготовь проект из бэкапа». Агент изучит исходные материалы, восстановит существующую структуру и добавит карточку темы по требованиям проекта. Архив сохранится целиком. Если проект был пустым, напишите: «Давай начнём работу над курсовой». Если ваш клиент не читает `AGENTS.md`, настройте чтение `.tt/agent-rules.md`. Установка сама по себе не запускает агента.

Агент использует ваше сообщение и предоставленные материалы, уточнит недостающие сведения и поможет создать `docs/topic.md`: тему на русском и английском, тип работы, курс и уровень образования, направление подготовки и краткое описание. Неизвестные поля можно оставить незаполненными; предложенный английский перевод считается предварительным, пока вы его не приняли. Карточка создаётся во время беседы, а не установщиком.

Дальше общайтесь обычными сообщениями: «Проверь введение» или «Руководитель согласовал новое название, обнови карточку». Завершённая подготовка не повторяется в следующих сессиях. Агент читает карточку и вносит принятые изменения. Карточка принадлежит вам и сохраняется при обновлениях ThesisTrail. [Описание сценария](docs/student-workflow.md).

## Исходные материалы

Сценарий библиотеки материалов также ещё не выпущен. Оригиналы хранятся в `materials/` по категориям: `articles/` — статьи, `books/` — книги, `regulations/` — нормативные документы, `guidelines/` — методические материалы, `other/` — остальные источники. Агент создаёт общий каталог `docs/materials.md` и зеркальные карточки: файлу `materials/articles/example.pdf` соответствует `docs/materials/articles/example.pdf.md`. В карточке указываются содержание, назначение, известные источник и версия, изученные страницы; непрочитанные документы отмечаются явно. Оригиналы исключаются из Git, а Markdown-описания сохраняются в репозитории. После клонирования оригиналы нужно предоставить заново или найти по сохранённым ссылкам на источники.

При подготовке из `.backup/` агент сначала проверяет назначение исходной папки. Если в `materials/` уже лежат код или графические ресурсы, он восстанавливает её на прежнем месте, а для документов использует свободную `research-materials/`. В Git игнорируется только выбранная библиотека документов; её путь записывается в каталоге. Для ответов по документам и цитат агент проверяет соответствующую часть оригинала. [Правила библиотеки и разрешения пересечений](docs/material-library.md).
