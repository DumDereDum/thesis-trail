# ThesisTrail

[ENG](README.md) | **RUS**

Инструкции и шаблоны для работы с ИИ, которые помогают студенту подготовить и защитить курсовую или диплом, а научному руководителю — проверить работу и подготовить вопросы.

## Установка

Запустите команду в папке своего проекта для установки из самого свежего по дате тега версии. Нужны Bash, Git и curl.

```bash
curl -fsSL https://raw.githubusercontent.com/DumDereDum/thesis-trail/main/scripts/install.sh | bash
```

[Подробности установки](docs/install.md).

Агенты с подключёнными инструкциями проверяют новые версии не чаще раза в сутки и спрашивают перед обновлением. [Подробнее об обновлениях](docs/update.md).
