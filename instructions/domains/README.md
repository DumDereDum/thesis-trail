# Domain instructions

## Available areas

No domain areas are included yet. Continue with the applicable general and research instructions; do not invent specialized requirements or create a missing area as part of an unrelated student task.

## Selecting instructions

1. Use the student's topic, accepted project decisions, current task, and this catalog's applicability descriptions to select available areas. A language, library, or keyword alone is not enough to apply every rule of an area.
2. Read the selected area's README and briefly tell the student which area applies at first use. If ambiguity would materially change the work, ask a focused question while continuing independent useful work where possible.
3. Follow the area's links to thematic files needed for this task. Reuse instructions already read; do not load every area, reread the collection on each message, or repeatedly announce the same selection.

Several areas may apply to one project. Combine only relevant instructions, preserving general rules and accepted project requirements. Clarify substantive conflicts rather than silently replacing a decision.

## Applying requirements

An area's required minimum applies within its stated scope. Conditional requirements apply only when their condition holds; recommendations allow adaptation. Use evidence appropriate to the requirement when checking results.

Match effort to the task. A routine edit does not by itself require a new report, an entire experiment, a new document, or renewed research framing. Keep the student's requested scope, existing authorization, and accepted decisions in effect.
