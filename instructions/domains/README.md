# Domain instructions

This catalog will link to instructions for particular subject areas as useful content becomes available. No domain modules are included yet.

Group future modules by subject, for example `ml/` for machine learning. Create a domain directory when it has actual instructions, and add a short catalog entry explaining when to use them. Do not add empty placeholders, author directories, or course profiles.

Each module should identify its applicability, relevant requirements or recommendations, and how to check the result. Link to general or research instructions instead of duplicating them. Select applicable modules from the student's topic and current task; do not read every domain for each project or message.
