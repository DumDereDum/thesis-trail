# Data analysis

## When to apply

Use for analytical datasets, indicators, dashboards, and conclusions drawn from data. Merely storing application records does not require a full analytical workflow.

## Baseline guidance

- Identify data sources, observation units, time coverage, and relevant sampling limitations.
- Describe cleaning and transformations, including treatment of missing values, duplicates, and inconsistent units.
- Define each reported indicator and check representative calculations against the underlying records.
- Explain what the results support and what remains uncertain; an observed association alone does not establish a causal effect.

## When relevant

- For scraped or combined datasets, check extraction failures, changing fields, and matching between sources before interpreting totals.
- For temporal comparisons, use consistent periods and definitions. For dashboards, verify that filters and aggregation levels preserve the intended meaning.
